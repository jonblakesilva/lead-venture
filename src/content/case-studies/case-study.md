A home service business in northwest Toledo came to us running on Squarespace, and like most Squarespace sites, it looked fine but performed terribly. Their PageSpeed score was sitting at 62 — a slow site, and slow sites lose customers, especially on mobile where people bounce if a page takes more than a couple seconds to load.

## Here's what we did

- **Moved off Squarespace entirely.** Squarespace is a website builder, not a performance platform. It's bloated by design because it has to work for every possible use case. We rebuilt the site on our own platform, built specifically for local service businesses, so there's no dead weight in the code.
- **Compressed and optimized every image and video.** Full-resolution photos and video straight off a phone will make a page crawl. We resized, compressed, and converted everything to modern formats so it loads fast without losing quality.
- **Put the whole site behind a CDN.** Instead of every visitor pulling data from one server, the CDN serves content from a location closer to them — that alone shaves real time off load speed.
- **Stripped out the code that wasn't doing anything.** Old plugins, unused scripts, extra tracking pixels — all the stuff that piles up on a website over time. If it wasn't earning its place, it got cut.
- **Minified and combined the code.** All the extra spacing, formatting, and separate CSS/JS files that make code readable for humans are dead weight for a browser. We compressed and combined files so the browser isn't making a dozen extra requests just to render the page.
- **Removed render-blocking resources.** A lot of Squarespace sites load scripts and stylesheets in a way that forces the browser to stop and wait before it can show anything. We restructured that so the important content shows up first.
- **Added lazy loading for images below the fold.** No reason to load a photo of the team or a gallery shot before someone even scrolls down to see it.
- **Set up proper caching.** Repeat visitors shouldn't have to redownload the whole site every time they come back.
- **Optimized fonts.** We limited font weights to what's actually used and loaded them in a way that doesn't block the page.
- **Cleaned up the DOM.** Squarespace tends to wrap everything in layers and layers of unnecessary divs and containers. We simplified the actual page structure, which helps both load speed and how easily search engines and screen readers can read the page.

## The results

| Metric | Score |
| --- | --- |
| Desktop performance | **98**/100 |
| Mobile performance | **79**/100 (up from 62) |
| Accessibility | 89 |
| Best practices | 96 |
| SEO | 100 |

That mobile jump matters most since most local searches happen on a phone. A faster site means fewer people leaving before the page even loads, which means more calls booked for a home service business that runs on same-day service calls.
